# Roadmap

## Shipped in 0.1.1

- Seeded insurance portfolio and independent fixture reference.
- Five-stage local workflow and five critical inserted scenarios.
- Endorsement reconciliation, duplicate/orphan payment checks, amount/date validation.
- Version-bound correction proposals and a reversible review ledger.
- Heuristic entity matching with reviewable associations.
- Optional OpenAI advisory investigation adapter.
- Before/after HTML reports, CSV outputs and evidence manifests.
- Automated tests, CI configuration, English documentation and runbook.

## Suggested 0.2

- More independent scenarios and a larger evaluation set, including offsetting errors and negative endorsements.
- Live AI evaluation with documented reviewer grading.
- A review interface backed by authenticated storage.
- Source-specific reconciliation tolerances, where justified by approved business rules.

## Later, separately scoped

- PySpark/Databricks adapter preserving the current contracts and scenario tests.
- Synthetic telecom example: account/subscription/customer grain and late events.
- Synthetic pharma example: patient/prescription/case relationships and restricted access.
- Event notifications and delivery acknowledgements.
- Production access management, approved retention and protected evidence storage.

These are proposed extensions, not completed modules or user commitments.
